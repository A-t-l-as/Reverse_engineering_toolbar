-> Aby móc konwertować tym sposobem należy posiadać imagemagick,
-> Pakiet imagemagick można pobrać np przez scoop:

lub
scoop install imagemagick

ENG:

-> To convert images this way, you need to have ImageMagick installed.
-> The ImageMagick package can be downloaded, for example, via scoop:
scoop install main/imagemagick
or
scoop install imagemagick
