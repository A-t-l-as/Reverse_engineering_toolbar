# Reverse_engineering_toolbar
A simple toolbar with applications for reverse engineering and modding – written in Python.

# Brief description

This Toolbar is a concept or idea, not a finished product. As every user has different needs, it is the user’s responsibility to configure the Toolbar themselves. The directories contain placeholders for the relevant executable files or entire directories where the executable files should be located.
The toolbar is launched via the Toolbar/toolbar.py file
